## Descripción

CampusRide es un sistema de movilidad compartida universitaria orientado a facilitar la coordinación de viajes entre miembros de la comunidad universitaria.

El proyecto contempla el diseño de maquetas funcionales, la implementación de la lógica de negocio, la gestión de cupos y la documentación de la arquitectura del software.
